## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/yourusername/vitaltrack-pro.git
cd vitaltrack-pro

# Install dependencies
npm install

# Environment setup
echo "VITE_GEMINI_API_KEY=your_key_here" > .env

# Run application
npm run dev
```

**Access**
Frontend: [http://localhost:3000](http://localhost:3000)
Backend: [http://localhost:8000](http://localhost:8000)

## 📊 API Example

**POST** `/api/analyze-meal`

```json
{
  "meal_description": "Grilled salmon with quinoa",
  "meal_type": "Lunch"
}
```

**Response**

```json
{
  "detected_dish": "Grilled Salmon with Quinoa",
  "ingredients": [
    { "name": "Salmon", "calories": 250, "protein": 45 },
    { "name": "Quinoa", "calories": 180, "protein": 8 }
  ]
}
```
